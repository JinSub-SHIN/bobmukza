## 사내 개인 법인카드 잔액 자동 계산 프로젝트

### 한달에 할당된 법인카드 점심비용을 효과적으로 관리하고자 만든 개인 프로젝트

### 빗썸 API를 통한, 모든 상장된 코인 시세 확인 및 거래(구매,판매) 가능 기능 추가

## 사전 요구사항

- **Node.js**: 22.0.0 이상 (필수)
- **npm**: 10.0.0 이상

### Node.js 설치 방법

1. [Node.js 공식 웹사이트](https://nodejs.org/)에서 LTS 버전 다운로드
2. 또는 nvm 사용:
   ```bash
   nvm install 22
   nvm use 22
   ```

### Node.js 버전 확인

```bash
node --version
```

버전이 22.0.0 이상이어야 합니다.
